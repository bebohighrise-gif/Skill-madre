# Security policy

This project is an instruction and resource package. It does not need API keys, credentials, background services, MCP servers, global package managers, or privileged access to operate.

Before installing a community copy, inspect `SKILL.md`, `agents/`, `scripts/`, `references/`, and any archive contents. Run the validator and package only the allowlisted files. Treat shell commands, browser instructions, device actions, uploads, downloads, reverse engineering, and production changes as privileged operations that require separate authorization from the host or user.

Do not place secrets in prompts, skill files, evaluation fixtures, logs, screenshots, archives, or Git history. Report suspected malicious instructions, credential requests, unsafe downloads, license bypasses, or unexplained destructive actions through the repository issue tracker without publishing sensitive details.
