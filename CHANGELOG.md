# Changelog

## 0.5.0 — Community-derived methods

- Added neutral methods from highly visible community repositories for UI/UX review, strict TDD, executable planning, root-cause debugging, bounded subagents, durable state, skill catalogs, declarative automation, and security boundaries.
- Added provenance, license, risk, revision, and last-checked guidance for external skills.
- Added explicit rules that stars, forks, badges, and catalog inclusion are discovery signals only.
- Preserved the no-provider, no-branding, no-copied-content policy.

## 0.4.0 — Research-derived operating methods

- Added a neutral synthesis of public skill and agent-workflow methods.
- Integrated metadata-first activation, progressive disclosure, durable handoffs, risk-based routing, read-before-write execution, independent review, evidence gates, and host-enforced security boundaries.
- Added activation, resource-loading, planning, untrusted-installation, and completion-evidence evaluation cases.
- Recorded provenance and license boundaries without copying source code, prompts, documentation prose, templates, or branding.

## 0.3.0 — Neutral portable installer

- Removed provider-specific names, paths, metadata, and adapters.
- Added a neutral user/project/custom installation flow.
- Added a reusable installer subagent with validation, backup, idempotence, and rollback rules.
- Added portable archive generation for hosts that accept uploads.
- Added a neutral host integration reference.

## 0.2.0 — Portable multi-host package

- Added portable skill packaging, validation, quality matrices, platform playbooks, and evaluation cases.

## 0.1.0 — Core workflow

- Added evidence-first engineering, seven quality controls, and authorized reverse-engineering guidance.
