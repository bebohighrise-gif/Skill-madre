# Observability, performance, and reliability

Load this module for incidents, missing operational signals, latency, memory, battery, frame rate, scaling, or reliability concerns.

For incidents, preserve timeline, versions, impact, symptoms, recent changes, and evidence sources. Correlate request, job, or transaction paths with stable non-sensitive IDs. Separate confirmed cause, contributing factors, impact, and unknowns. Source code that emits a metric or log does not prove collection, alert delivery, or operational usefulness.

For performance, define workload, device/runtime, environment, sample size, and budget. Measure a comparable baseline, change one meaningful variable, repeat the measurement, and report variance and limitations. Bound queues, concurrency, payloads, memory, retries, and time. Verify cancellation, shutdown, navigation, backgrounding, cleanup, overload, and degraded dependencies where relevant.
